About this SQLi website

SQLiDemo is an educational workspace that demonstrates how unsafe input can affect database queries. Use the practice area with sample data only, compare unsafe and parameterized approaches, and observe why validation and prepared statements matter.

⚠ This project is for authorized local learning. Never test systems or data without permission.

Backend code · illustrative example

// Prefer parameterized queries in production
String sql = "SELECT * FROM users WHERE username = ?";
PreparedStatement stmt = connection.prepareStatement(sql);
stmt.setString(1, username);
ResultSet results = stmt.executeQuery();

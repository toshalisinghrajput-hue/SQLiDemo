How SQL injection works

SQL injection occurs when an application places an untrusted user input directly into a database SQL query. An attacker may manipulate that input to execute unintended SQL commands that the database interprets as part of the query itself.

1. User inputThe user enters information into an application's input fields, such as username or email address and password.
2. Query ConcatenationIn a vulnerable application, the user input may become part of the SQL statement instead of remaining as ordinary data.
3. Secure the queryParameterized queries treat user input as data, preventing the input from changing the query structure.

How SQL Injection is Prevented

The primary defense demonstrated in this project is the use of the parameterized queries. Applications should also follow secure database practices, validate input appropriately, use least privileged database accounts, use prepared statements, and keep detailed security logs.

Key takeaway: Never allow untrusted input to become part of a SQL query structure.
